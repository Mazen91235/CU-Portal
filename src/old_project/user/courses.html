Course Description

This course covers the fundamental concepts of operating systems including process management, memory management, file systems, and system security. Students will learn about various operating system architectures and gain hands-on experience with system programming.

Course Objectives

  • Understand the fundamental principles of operating systems
  • Learn about process management and scheduling algorithms
  • Study memory management techniques including virtual memory
  • Explore file system design and implementation
  • Gain practical experience with system programming

Prerequisites

Computer Science Fundamentals (CS101), Data Structures (CS102)

Assessment

  • Midterm Exam: 30%
  • Final Exam: 40%
  • Programming Assignments: 20%
  • Class Participation: 10%
