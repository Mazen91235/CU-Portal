Assignment 2 - Operating Systems

Assignment Description 

## Assignment Overview
In this assignment, you will implement a basic file system that supports:

### Requirements:
1. **Directory Structure**: Implement a hierarchical directory structure
2. **File Operations**: Create, read, write, and delete operations
3. **Inode Management**: Proper inode allocation and deallocation
4. **Free Space Management**: Implement free block management
5. **Error Handling**: Proper error handling for all operations

### Deliverables:
- Source code files (.c, .h)
- Makefile for compilation
- README with compilation and usage instructions
- Test cases demonstrating functionality

### Grading Criteria:
- Correctness (40%)
- Code quality and documentation (30%)
- Test coverage (20%)
- Performance optimization (10%)

### Submission Guidelines:
- Submit as a ZIP file
- Include all source files and documentation
- Ensure code compiles without errors
- Include sample test cases
