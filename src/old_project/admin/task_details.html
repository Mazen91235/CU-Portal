Assignment Overview
In this assignment, you will implement and analyze various tree data structures including binary search trees, AVL trees, and B-trees. This will help you understand the performance characteristics and use cases for different tree structures.
Requirements:
Implement a binary search tree with insert, delete, and search operations
Extend the BST to create an AVL tree with proper balancing
Create a B-tree implementation for database indexing simulation
Write comprehensive unit tests for all implementations
Provide time complexity analysis for all operations
Deliverables:
Source code files (.java or .cpp)
Unit test files
Analysis report (PDF, max 10 pages)
README with compilation and execution instructions
Grading Criteria:
